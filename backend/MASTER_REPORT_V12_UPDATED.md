# مركبات V12 — تحديث Hardening / UX

تم تحديث الحزمة الحالية بناءً على آخر الملاحظات:

## 1) الحساب والقائمة الجانبية
- قائمة الثلاثة خطوط أصبحت مرتبطة بالحساب.
- الملف الشخصي.
- مركباتي.
- المزادات والمزايدات.
- الإشعارات مع عداد غير المقروء.
- طلبات نقل الملكية.
- الأمان وتسجيل الدخول.
- التحقق من الهوية.
- الدعم الفني واتصل بنا.
- تسجيل الخروج.

## 2) الإشعارات
- تم نقل التخزين من Map داخل الذاكرة إلى Prisma/PostgreSQL.
- عداد غير المقروء.
- تعليم إشعار كمقروء.
- تعليم الكل كمقروء.
- تحديث تلقائي كل 15 ثانية في صفحة الإشعارات.
- ربط الإشعارات بالعمليات عبر operationId.
- إضافة إشعار عند إنشاء تذكرة دعم وعند وجود مزايدة جديدة.
- إشعارات عمليات البيع الموجودة في service أصبحت قابلة للحفظ بشكل دائم.

## 3) الدعم الفني / اتصل بنا
- صفحة دعم مستقلة.
- إنشاء تذكرة برقم مرجعي.
- التصنيف والأولوية والعنوان والوصف.
- صفحة محادثة للتذكرة.
- متابعة الحالة والردود.
- إغلاق/حل التذكرة يمنع إضافة رد جديد من العميل.

## 4) المزادات
- صفحة مزادات فعلية من قاعدة البيانات.
- فلترة تلقائية من بيانات المركبة: الماركة → الموديل → السنة.
- لا تعتمد الفلترة على عنوان الإعلان.
- الحد الأدنى 50,000 YER.
- منع البائع من المزايدة على مزاده.
- المزايد يحتاج هاتفاً موثقاً.
- منع المزايدة إذا انتهى المزاد.
- منع المزايدة الأقل من السعر الحالي + الحد الأدنى للزيادة.
- Anti-sniping: إذا تمت مزايدة خلال آخر دقيقتين تتم إضافة دقيقتين.
- حماية تحديث السعر والمزايدة داخل transaction.
- منع إدخال المركبة في أكثر من مزاد نشط.
- منع المركبات غير النشطة.
- منع المركبات المحجوزة بحالة حكومية RESTRICTED/BLOCKED.
- منع المركبات التي عليها مخالفات PENDING.
- ربط بيانات المزاد بالمركبة الفعلية.

## 5) البيع ونقل الملكية
- لم يتم حذف نظام Escrow أو عقد البيع أو حالات العملية.
- رسوم النقل ثابتة 80 USD، ويتم تحويلها إلى YER حسب سعر الصرف المثبت وقت العملية.
- مدة إكمال نقل الملكية تبقى ساعتين حسب القرار الأخير، ويجب الحفاظ عليها في workflow.
- بيانات العمليات القديمة تبقى موجودة.

## 6) قاعدة البيانات
تمت إضافة:
- Notification
- SupportTicket
- SupportMessage

ويجب تنفيذ:
- `npx prisma generate`
- `npx prisma db push` أو migration في بيئة قاعدة البيانات الفعلية.

## 7) ملاحظة الاختبار
تمت مراجعة الملفات بعد التعديل. لم يكتمل `npm install` داخل بيئة الفحص بسبب انتهاء المهلة الزمنية، لذلك لم يتم الادعاء بأن build الإنتاج تم تشغيله بنجاح هنا. الحزمة تحتوي على الكود والتغييرات المطلوبة، ويجب تنفيذ التثبيت ثم Prisma generate ثم build على بيئة Vercel/CI.
